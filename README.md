Project Title: FlexStep | Scalable E-commerce Engine

The Summary:- Full-featured e-commerce platform built using Django and SQLite. This project focuses on the "Batteries Included" philosophy, leveraging Django’s built-in security for authentication and transaction management.

Key Features:-

  Dynamic Cart Logic: Custom context processors to handle shopping cart sessions across the site.

  Secure Payments: Integrated Stripe API for encrypted,payment processing.

  Complex ORM: Managed many-to-many relationships for product categories, tags, and variants (brand/colors).

  Admin Dashboard: Fully customized Django Admin to manage inventory, track orders, and view sales analytics.
